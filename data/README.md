# Sample data provenance

`sample_prices.csv` is generated by `mafinrisk sample --seed 42`. It is entirely synthetic, freely redistributable as part of this MIT-licensed project, and does not reproduce any instrument's historical returns.

- Six fictional indices: US equity, European equity, emerging-market equity, government bonds, corporate bonds, and gold.
- All start at 100. The labels identify illustrative asset classes, not investable tickers.
- 1,009 prices; 1,008 simple returns; business-day labels beginning 2021-01-04.
- Correlated Gaussian log increments with a fixed loading matrix plus independent residual variance. Parameters are specified in `src/mafinrisk/data.py`.
- Geometric price construction ensures strictly positive prices. The annual drift parameters describe the simulation, not guaranteed sample means.
- No historical calibration, transaction costs, exchange calendar, currency conversion, or dividends.

To regenerate the committed example figure and metrics:

```bash
mafinrisk sample --seed 42 --output data/sample_prices.csv
mafinrisk analyze --prices data/sample_prices.csv --output docs \
  --source-label "Synthetic demonstration"
```

The generated results are committed to make the repository immediately inspectable. The seed and generation recipe permit reproduction; floating-point values can differ slightly across dependency/platform versions. `docs/environment.txt` records the versions used for the checked-in results.
